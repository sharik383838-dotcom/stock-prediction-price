# AI Stock Market Predictor

A modern, fast, and simple web application that forecasts the next trading day's closing price for any global or Indian stock market ticker using Machine Learning (**RandomForestRegressor**), technical indicators, and real-time market data from Yahoo Finance.

Built with **HTML5**, **CSS3**, **Vanilla JavaScript**, **Chart.js**, and **Python Flask**.

---

## 🌟 Key Features

- **Real-Time Market Data Integration**: Fetches actual, unmanipulated historical stock records via `yfinance`.
- **Machine Learning Price Forecasting**:
  - Predicts the next trading day's closing price using Scikit-learn's `RandomForestRegressor`.
  - Engineers technical features: lagged prices, Simple Moving Averages (5, 10, 20 SMA), Exponential Moving Average (12 EMA), moving average distances, High-Low spread, and volume moving averages.
  - Strict **chronological train/test splitting** (80% train, 20% test) to prevent future data leakage.
  - Computes out-of-sample **Mean Absolute Error (MAE)** to honestly evaluate model accuracy.
- **Modern Dark Purple UI**:
  - Elegant deep purple theme (`#0a0716`) with bright purple accents (`#a855f7`).
  - Glassmorphic card styling, subtle glowing effects, and smooth hover/fade-in animations.
  - Responsive layout optimized for desktop, tablet, and mobile browsers.
- **Interactive Stock Graph (Chart.js)**:
  - Visualizes the past 60 trading days of actual closing prices.
  - Clearly projects the predicted next trading day as a **separate highlighted point** with a dashed projection connector.
  - Custom dark purple tooltips with distinct actual vs. predicted labels.
- **Dynamic Indicators & Controls**:
  - Live **Bullish ↗** vs. **Bearish ↘** trend badges.
  - Expected price change (nominal and percentage).
  - Quick symbol selector pills (`AAPL`, `TSLA`, `RELIANCE.NS`, `TCS.NS`).
  - Graceful error handling for invalid or inactive tickers.

## 🚀 Getting Started

### 1. Prerequisites
Ensure you have Python 3.9+ installed on your computer:
```bash
python --version
```

### 2. Clone or Navigate to the Project Directory
```bash
cd "c:\Users\Dell\Desktop\stock prediction price"
```

*(Optional but recommended)* Create and activate a virtual environment:
```bash
# On Windows:
python -m venv venv
venv\Scripts\activate

# On macOS/Linux:
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the Flask Web Application
```bash
python app.py
```

### 5. Access the Dashboard
Open your browser and navigate to:
```
http://127.0.0.1:5000
```

## 📡 API Endpoints

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/` | Serves the single-page web dashboard (`index.html`) |
| `POST` | `/predict` | Accepts `{ "ticker": "SYMBOL" }` and returns JSON with predictions, MAE, trend, and historical chart data |
